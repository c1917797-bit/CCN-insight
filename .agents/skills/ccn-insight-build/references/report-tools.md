# CCN 报告工具选择 · 2026-10-23

用户希望从 ywqppt 与 Mozhi 工作区方法中选择稳定方案。按交付件确定工具，避免每轮换渲染器：

| 交付件 | 本项目主选 | 原因与边界 |
| --- | --- | --- |
| 日常洞察网站 | 现有 CCN 阅读器与统一内容表 | 保留检索、地图、跨专题关联和可更新数据，不把网站重做为幻灯片 |
| 滚动式专题/洞察报告 | hw-ppt-gen-html 的 Report 流程 | 篇幅适应图与论证，关键图可清晰展示；实际采用时执行 Humanize、Report 导出与独立视觉 QA，不能只读说明就称已执行 |
| 需要可编辑 PowerPoint | ywqpptpro | 趋势、方向、技术、结果与观点关联更完整；按实际需要生成，保留真实图、条件和版面验收，不把所有网站页面强制套为一文一页 |
| 短平快固定模板 PPT | ywqppt，作为可选 | 内容很短且模板合适时使用；不作为当前网站默认工具 |

本决定来自工具契约和本项目阅读需求，不是同内容生成的盲测排名，也不说明Pro或某作者的工具天然优于其他。既有PPT继续保留；用户本次没有要求重新导出，不因此替换附件。

内容层吸收 `ppt-deep-search` 的来源理解、单页报告的问题—方法—效果和 `ccn-report` 的有条件完整技术摘要；PPT专用的固定物理尺寸、字体、每页字数与禁动画规则不变成网站规范。

`ywqpptpro` 的预览确认与固定模板属于实际生成该类PPT时的工作流。网站普通迭代使用当前用户授权，不额外引入PPT审批轮次。所有执行状态记录在 `.agents/skill-provenance.json`，区分已执行、只读借鉴和未来选择。
