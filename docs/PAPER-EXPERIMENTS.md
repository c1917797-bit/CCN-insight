# 论文实验效果：唯一维护与阅读

唯一可编辑表：`data/compression/tables/ic_paper_experiments/rows.jsonl`。
阅读器在16个专题的比较章共用同一个组件，首屏和速览均提供“实验效果对照”入口。
表格、检索索引和静态读取包均为生成视图，不另行维护数值。

## 记录什么

一行对应同一论文、版本和条件下的一个实验。不同质量、计时负载或硬件拆行。
`experiment_id`保持稳定；同一论文可有多行。联合W/A/KV实验仅保存一份，
通过`topic_ids_json`关联已有专题；每个专题必须有指向该论文的显式来源引用。
`card_id`指向现有解读，用于从效果表返回机制与方法，不能把别篇论文的证据借给本条。

保留方法与首次发表年、PTQ/QAT等准备方式、实验层级、模型、W/A/K/V具体格式、
粒度与旁路、基线、任务/数据、硬件、运行栈、负载、校准/计时协议。
准备方式和压缩对象是不同维度。整数、浮点、非均匀码本不能仅按位宽合并。

质量、性能、内存各用一个指标数组。每项包含指标名、原基线、压缩结果、单位、
优劣方向和适用范围；不只保留一个倍数。页面计算`Δ = 结果 − 基线`，
准确率百分数之差显示为百分点，PPL保持PPL。驻留和峰值内存分别记录。
内核、完整模型系统实验分别标注，内核耗时不换名为TTFT/TPOT。

数组为空时必须给出`not_reported`（本实验未报告）、`not_checked`（尚未核对）
或`not_applicable`（不适用）。不得用零代替缺失，不得把同论文另一组实验填入空格。
有指标才可用`reported`。`review_depth=section_review`仅指指定方法/结果章节核对，
不升级旧卡的摘要审阅状态，也不表示全文阅读或独立复现。
