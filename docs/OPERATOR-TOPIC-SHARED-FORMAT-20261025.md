## 实现范围

十二个专题页：计算/通信两个分支，九个机制专题，自动生成与调优一个横向方法专题。总入口仍保留上一轮五栏目。

所有专题均采用：速览与证据、研究背景、基本原理、关键挑战、技术进展、比较判断、研究结论七章。旧methods/hardware/evidence/projects/research和证据锚点继续存在，作为对应主章内的子级；没有增加中间跳转页。

共用原有推理压缩的 `original-reader/site/business_insight/cloud_core/topic-studio.css`，没有复制一个算子专用topic-studio。原压缩选择器保留在:is分支内，另一个分支只匹配含data-operator-topic的页面；算子通过structured-topic、compression-topic-hero、research-overview-section、expert-topic-entry和topic-dossier-card等同类结构复用阅读面。

页首展示从实际页面计算的案例数与关联来源数。原核心判断移至速览，减少重复。速览为核心判断、代表路线、证据现状、关键缺口四项；内容投影自原有judgment、catalog、canonical records和unresolved questions，不另维护一份技术结论。

证据导航按全部、产业、学术、待读筛选，可直达案例或来源核对范围。筛选仅作用于导航索引，正文不折叠、不隐藏。页内检索从当前渲染的章节和案例文本生成跳转结果，不把没有命中解释为技术不存在。

待读沿用压缩的浏览器存储键ccn.expert.saved.v1，算子记录加operator:前缀，避免与压缩卡片ID冲突；增删保留同一存储中的其他记录。界面明确浏览器本地保存，存储拒绝时显示失败而不宣称已保存。
