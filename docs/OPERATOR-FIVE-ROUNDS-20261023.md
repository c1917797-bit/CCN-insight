## 五轮记录

1. **阅读层级**：审查13页。计算/通信分支先给机制对照与路线，再进入案例；9机制首段提炼技术改变、核心取舍与关注场景。结尾增加可推翻判断的条件。增量构建和原有算子约束校验通过；浏览器确认计算页正文顺序、无折叠和无整页溢出。
2. **证据表达**：逐项人工标明接口能力、机制、内核性能、模型阶段性能、合成数值与训练参考；能力说明采用中性色，性能结果保留条件。加入总览技术判断、文献角标返回正文。复核FA4、FLUX、AscendOptimizer原文及通信官方资料；浏览器确认类型和出处返回入口实际渲染。
3. **机制与研究判断**：计算加入Stream-K的分解/归约成本与退化区间、Marlin的INT4存储/FP16执行；修正融合的寄存器需求与并发驻留方向、FA2不同Split-K层级。CannBot加入非恒定跨tile输入测试设计及RMSNorm整行统计手算反例。通信修正单launch与打包区别、注册与PXN互斥、通算关键路径、KV与MoE编码分工；33条进展均与专家镜像同步。9页研究启示各自解释机制取舍，生成方法仅作关联。独立内容审稿和浏览器核验通过。
4. **视觉与交互**：重绘原生等距数据流与芯片SVG，低幅动态可暂停；统一标题、事实、观点、条件和来源的层次。窄屏比较表转为带字段名的记录，机制图上下排布并提高关键标签字号。新增长页直达、技术名/别名检索、嵌套目录跟随、正确案例落点与紧凑可返回书目。增量构建、约束校验及视觉检查完成。
5. **独立复核与实点修复**：三位独立审阅者复核计算、通信和阅读路径。修复正向条件误入失效栏、目录顺序、减少动效状态、图重放范围不对应、Mooncake控制面表述和标点；浏览器另发现旧JS缓存，已按文件内容散列为CSS/JS生成版本。实际点开9机制、2分支、总览、生成页，检查5个系统实验锚点、9组搜索、角标往返与嵌套高亮。最后增量构建及算子校验通过。
