# 本月论文数量矩阵的维护口径

矩阵回答“本月新发表、已经从指定来源取得并完成摘要归类的论文有哪些”，精选进展回答“其中哪些值得深入阅读”。两者分别统计；不能用精选的 16 篇冒充全月数量，也不能把所有检索命中当成相关论文。

## 唯一维护源

- `data/compression/tables/ic_monthly_paper_corpus/rows.jsonl`：每篇论文的身份、日期、原始摘要 SHA-256、归类、理由和不确定项；不在前端根据标题重新分类。
- `data/compression/tables/ic_monthly_corpus_snapshots/rows.jsonl`：月份、采集截点、来源主体 ID、原始检索式、采集与判定记录哈希、覆盖边界。
- 阅读界面：`original-reader/site/business_insight/cloud_core/monthly-corpus.js`；索引和数字从同一表重算，不维护另一份手填计数。

来源必须已经存在于 `ic_source_families`。2026-10-29 这批是登记在册的 arXiv 平台官方 API 快照，不能说其他论文入口、会议或产业来源已经做过同等月度扫描。未纳入的来源不是零篇。

## 日期、身份和总量

1. 主矩阵按 `first_published` 的自然月统计，截止采集快照。旧文在本月的修订不进入首发矩阵；精选可另收修订，但必须明确日期依据。
2. 同一 arXiv 论文去掉版本号后是一个身份。摘要与判定不一致的重复版本必须复核，不能任意覆盖。
3. 一篇论文可以归入多个实际成立的对象×方法组合。每格、每行及全矩阵各自按论文 ID 去重；格子相加不是论文总量。
4. 3×4 主矩阵仅包含四类根技术；Token 合并、KV 淘汰、GQA/MQA、高效缓存架构另外展示。“已归入专题”包含扩展机制，矩阵合计只指主矩阵。
5. 检索候选分为 `classified`、`related_unmapped`、`pending`、`excluded`，四者构成互斥分区。只有第一类有明确专题关系；待核实与未归类不填入任意格子。

## 摘要归类规则

必须读原始摘要，按论文的实际贡献或明确分析对象归类。标题、关键词命中、背景提及、实验基线不能独立建立关系。不要把多个对象与多个方法做笛卡尔积。

- 权重/激活/KV 分别判断。量化校准使用激活统计，不意味着压缩激活；权重投影量化不意味着 KV 被量化。
- 静态权重、层、通道和专家裁剪通常归权重；推理时按输入裁剪 token/中间计算才可能归激活。历史缓存 token/页淘汰归 KV 淘汰扩展，不混进 KV 特征/通道剪枝。
- 教师监督必须明确产生更小或部署成本更低的学生，才能记为压缩蒸馏。普通能力迁移、自蒸馏、训练数据生成和特征对齐不是天然压缩；特征监督本身不构成激活压缩。
- 低秩 LoRA/PEFT 只改善训练参数或训练内存，不能自动当作部署权重分解。注意力中间矩阵低秩与持久 KV 低秩缓存分开。
- 只读取更少缓存但未删除缓存，不标为 KV 淘汰；前缀缓存跨请求去重不标成 GQA/MQA 头共享。
- 训练梯度、优化器状态压缩以及图像/通信码流量化不是模型推理压缩；其他领域模型（视觉、语音、翻译等）可以纳入，不因暂未匹配某业务而删除技术。
- 用户本轮明确暂不纳入生成式扩散/流模型压缩及扩散步数蒸馏：保留身份及理由，标 `excluded` 与 `reason_code=diffusion_out_of_scope`。图论中的 diffusion 不仅因同名就排除。
- 摘要未明确对象、部署变化或压缩机制时，保留待核实/相关未归类；不为填满地图猜测。摘要研读不升级为全文研读、同行评审或独立复现。

## 更新与验收

先保存已登记来源的原始获取记录和摘要，再逐篇生成判定；导入器 `scripts/import_monthly_paper_corpus.py` 只验证/落表，不做关键词自动分类。新增月份需显式提供相应日期和快照，不能把本脚本固定的 2026-10 导入当作无人值守采集器。确认同月所有命中均有判定、哈希对应、身份唯一、来源存在，再构建、验证并发布。

`node scripts/test_monthly_paper_corpus.cjs` 检查首发日期、版本去重、跨格合计、来源登记、摘要依据、扩散排除、缺页和异步切月。`scripts/build.py` 派生运行数据；不直接改 `dist/`。真实浏览器还需点击数字，核对列表、归类理由、清空/翻页、其他月份缺数说明及窄屏。

新增信息会改变候选集合、归属或不确定状态；保留快照 ID 和提交记录。若发现误归类，应修改该篇判定并重算，而不是只手改一个数字。其他来源补齐后需要跨来源论文身份匹配，不能把会议版本与预印本相加。
