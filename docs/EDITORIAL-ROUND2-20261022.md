# 第二轮：减少阅读干扰，明确实验设计

状态：本地审阅。CCN 公开站和原站均未发布本轮修改。

## 读者可见的变化

1. 信息来源页默认只显示信源目录，不加载候选论文工作队列。点击“资料处理工作台”后才读取候选、研读与处理记录；原来的 `#imported-paper-review` 深链接继续可用。“返回信源目录”可以收起工作队列。
2. 16 个专题的验证建议统一为五项：验证对象、对照方案、测量指标、继续条件、停止条件。保留具体方法与模型适用条件，以定义列表完整展开，不增加折叠。
3. 目录筛选项改用“研究用途”“收录范围”等便于理解的名称。只有一页时不显示无效的翻页按钮。状态行仅保留信源及入口数量。
4. 验证清单采用固定标签列、流式正文列；窄屏改为上下排列。继续条件和停止条件分别轻度标色。

## 内容边界

本轮修改的是研究建议卡片，不把它们改写成已测结果。原有论文实验数字、出处、版本和审阅日期保留。各类设备的实际支持与收益仍需相应业务验证；950 完整型号仍待确认。PPT/PDF 附件没有重制。
