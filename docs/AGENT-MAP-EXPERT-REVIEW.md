## 保留的报告结构

信息来源 → 技术地图 → 本期动态 → 分析结论 → 洞察归档。

三项研究仍为依赖感知排程、状态感知映射、干扰感知分配。划分依据是主要决策变量：启动时机与次序、执行绑定、额度与资源容量。它们可以联合求解；此组织方式不宣称为行业统一标准，也不等于完整 Agent 系统功能分类。

信源目录仍为热点资讯、产业界、学术界三张表。咖啡示例保留在全景说明中，明确教学边界；原来的对象、决策、演示锚点继续可访问。新增深读按历史研究依据呈现，不冒充当月新论文。

## 对参考产品的实际吸收

参考 [MozhiJiawei/ccn-report 固定版本](https://github.com/MozhiJiawei/ccn-report/tree/0a028222aeffa7752a56cdf805a3a719ab30e97e) 的机制叙述、原图邻近说明和技术取舍方法。未复制其整套导航、视觉模板或大体积内嵌图片。方法约定见 [报告写作规范](AGENT-REPORT-AUTHORING.md)。

- 重要研究采用“具体问题 → 决策过程 → 原始实验 → 边界 → 本报告取舍”。
- 教学数字与论文测量分开；图形应呈现状态变化及反例，不能只画几只概念框。
- 关键数字连同硬件、负载、基线和 SLO 阅读。Murakkab 的部分对照存在时限违约；表内比值与摘要倍数的差异原样说明。
- 新增资料使用独立 CSV 维护来源、实验数值与图片出处，不写不可维护的大 JSON。
- Sites 技能用于现有站同步和发布；PDF 技能用于原论文读取、渲染和原图核对。未运行 GROBID/Docling，也未以“看过 skill”声称完成整个 PPT 生产流程。

## 验收与边界

本地完整构建与主站校验通过；Agent 专项校验覆盖 23 页、页面章节与内部链接、三类信源表、三根机制 SVG，以及原图源文件—独立产物—dist 的字节一致性。

浏览器实际点击五个主栏目、三根专题、深读与咖啡入口；检查桌面和 390px 手机视口。咖啡“两个查询、一个名额”能显示一个执行、一个就绪等待。重点图和机制截图由另一个审查者独立核看；密集论文三联图在正文用于概览，通过原尺寸入口看细节。

这是阅读体验与证据组织的改造。没有完成真实云核性能实验，没有重新全文核验所有历史论文，没有证明首屏加载稳定小于两秒。站点仍为人工构建的只读快照；GitHub 推送与 Sites 发布分别记录。
