# 技术地图中英文切换

技术地图右上角的 English／中文按钮原地切换语言。范围包括技术地图正文、折叠详情、图中文字、导航及咖啡教学演示的运行状态。研究专题子页面和其他主栏目保持各自现有语言。

- 中文内容继续由现有 Python、CSV 维护；英文翻译在 `research/agent-scheduling/map-en.json`。
- `map-language.js` 在构建时与词典合并进有内容散列的脚本，无翻译接口、网络请求或额外框架。
- 语言选择保存在当前浏览器；`?lang=en#map`、`?lang=zh#map` 可指定初始语言。按钮不修改锚点、依赖、调度策略、计时和执行状态。
- 运行时新增的文字同样切换，中文恢复使用原文字；SVG 英文按节点可用宽度排入边框。
- 其他主栏目恢复中文；返回地图继续使用上次地图语言。手机英文主导航在自身容器内横向滚动。

维护后运行 `scripts/build_agent_report.py` 和 `scripts/verify_agent_report.py`。后者包含 `check_agent_map_language.py`，检查地图和共用导航的静态中文文字、辅助标签都有非空英文，防止增量正文缺少翻译。
