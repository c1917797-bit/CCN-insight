1. **原始获取**：本轮 arXiv 保存响应中实际取得的唯一论文 ID。检索返回 4,825 篇，另补入18篇经典种子，共4,843篇；获取摘要不代表领域相关、全文阅读或推荐。
2. **本月首发候选**：从原始获取中，按论文首次发表日期选出10月首发的1,728篇。其余3,115篇属于其他首发月份。旧文10月修订和经典种子不能混进首发量。
3. **推理压缩方向**：独立判断是否涉及神经模型部署体量、输入上下文或内部运行表示的压缩。允许现有技术地图尚未覆盖的机制；该层不是业务收益验证，也不是论文质量排名。
4. **现有技术地图**：确认明确的对象与方法后才分配已维护的16个专题标签。领域相关但不适合现有格子的研究，保留在图外队列；不为让统计闭合而强行归类。
5. **四类根技术主矩阵**：现有地图里的12个对象×根技术单元格；另外4个扩展方向单列。每层均按去掉版本号的论文ID去重。

本轮领域判断以神经模型为范围，包括LLM、视觉、语音、翻译和降噪等。单纯训练优化、LoRA训练参数节省、调度与卸载、外部音视频/检索数据编码、非神经模型推理算法等保留为相邻材料。生成式扩散/流模型按维护者要求暂不纳入；组合系统中可明确分离的非扩散神经模型压缩贡献可保留。

领域状态为 `in_scope / adjacent / unresolved / out_of_scope`，各篇只占一组。它与地图的 `classified / related_unmapped / pending / excluded` 是两组独立判断。不能直接相加旧的465地图论文和255相邻论文来冒充领域总数，也不能把旧地图排除自动当成领域排除。

领域判断的摘要SHA、理由、边界和日期进入同一份canonical记录；旧地图归属保持独立。已归图465篇沿用其已有摘要/指定章节证据；195篇生成式扩散沿用明确的范围排除。其余1,068篇补做独立原始摘要领域判断。未明确的保留待核，不靠标题自动定论；该轮工作不提升到全文审阅或实验复现。

采集事实见 monthly-acquisition-audit-20261030.json；领域审阅与可重算集合见 monthly-domain-review-20261030.json 和 monthly-domain-funnel-audit-20261030.json。`scripts/audit_monthly_corpus.py` 从唯一维护源重算，读取器和 `test_monthly_funnel.cjs` 另行验证集合包含关系及点击后清单。

请求窗口是2026-08-01至2026-10-29，保存记录最新首发/更新日期实际为10月27日；不能据此声称28–29日没有相关论文或全月已完整覆盖。来源查询回显未保留修订日期条件，修订覆盖尚未建立。未计量的其他登记来源不是零篇。完整获取审计保留26份响应的哈希与逐页数量。
